# Misión tortuga ninja

Para mi tortuguita ninja, en su cumpleaños. No hay nada que instalar: solo abre la página y empieza.

**Tu misión**

1. Cada barrica de vino guarda una letra. Para abrirla tienes que resolver su sudoku.
2. Los sudokus suben de cinta, de blanca a negra. Tómate tu tiempo, no hay prisa ni límite.
3. Tu avance se guarda solo en este navegador, así que puedes dejarlo y volver cuando quieras.
4. Cuando abras todas las barricas, las letras juntas forman una palabra. Esa palabra es la contraseña de tu regalo, que te mandé por WhatsApp. Escríbela con las letras tal como aparecen, en mayúsculas.

Si te equivocas en un sudoku, puedes borrarlo con el botón de arriba y empezarlo de nuevo.

**Cómo está protegido tu regalo**

- Es un PDF con contraseña, cifrado con AES-256. Sin la contraseña es solo un archivo ilegible.
- El PDF no está en esta página: te lo mandé aparte. La contraseña solo se descubre aquí.
- Las letras de las barricas también están selladas. Cada una se cifró usando la solución de su sudoku como llave, así que la letra solo se puede abrir resolviendo el sudoku.

Feliz cumpleaños, tortuguita. 🐢🍷
