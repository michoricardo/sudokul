# Para ti, en tu cumpleaños

Aquí no hay nada que instalar. Solo abre la página y empieza.

**Cómo funciona**

1. Cada barrica guarda una letra. Para abrirla tienes que resolver su sudoku.
2. Los sudokus se van poniendo más difíciles. Tómate tu tiempo, no hay prisa ni límite.
3. Tu avance se guarda solo en este navegador, así que puedes dejarlo y volver cuando quieras.
4. Cuando abras todas las barricas, las letras juntas forman una palabra. Esa palabra es la contraseña de tu regalo. Escríbela con las letras tal como aparecen, en mayúsculas.

Si te equivocas en un sudoku, puedes borrarlo con el botón de arriba y empezarlo de nuevo.

**Cómo está protegido tu regalo**

- Tu regalo es un PDF con contraseña, cifrado con AES-256, el mismo tipo de protección que se usa en documentos bancarios. Sin la contraseña es solo un archivo ilegible. Se cifró en una computadora, sin subirlo a ningún sitio de internet.
- Al pulsar «Abrir mi regalo», tu navegador abre el PDF y te pide la contraseña. Escribe ahí tu palabra.
- Las letras de las barricas también están selladas. Cada una se cifró usando la solución de su sudoku como llave, así que la letra solo se puede abrir resolviendo el sudoku. No hay otro camino.

Feliz cumpleaños. Disfruta cada barrica.
